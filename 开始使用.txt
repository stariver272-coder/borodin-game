鲍罗廷的秘书：三次抉择 — 开始使用

这个 ZIP 是网页项目的源代码，包含前端、服务器接口、三幕台本、投票逻辑、人物图片管理和测试。
不是双击 HTML 就能运行的离线成品。参与者只需要浏览器，不需要下载源码。

一、参与者之间怎么连接？

所有设备连接同一个服务器。主持人发送推进或截止指令，玩家发送投票，服务器保存统一的房间状态；各页面约每 2.5 秒读取更新。
房间码只选择场次，不会自动连接两台彼此不可达的电脑。

方案 A：使用网上的网址

现有网址：https://borodin-council.mysticpond1024.chatgpt.site
主持人和玩家都打开同一个网址，主持人创建房间，玩家输入昵称和房间码加入。
大家不需要同一个 Wi-Fi，可以分别使用家中宽带、学校网络或手机流量。
前提：都能访问这个网址，并具有网站访问权限。网站访问权限和房间码是两个层次。
当前版本最初以私密预览发布；邀请他人前请在网站共享设置中确认权限。
网上的服务器负责同步，主持人的电脑不需要充当服务器。

方案 B：让主持人电脑提供局域网服务

通常大家连同一个路由器的 Wi-Fi，或连主持人提供的同一个热点。
主持人电脑启动一份服务，手机打开“主持人电脑的局域网 IP + 端口”，进入同一房间。
例如：http://192.168.1.10:5173/ 。这里的 IP 只是示例，必须换成主持人电脑实际的 IPv4 地址。
同一 Wi-Fi 不一定允许互相访问；校园/访客网络可能隔离设备。此时可换允许设备互访的网络或使用网上网址。
活动期间主持人电脑、服务进程和网络都要保持运行。

不能这样连接：每个人各自解压并运行自己的服务，再输入相同房间码。那是多份独立数据库，投票不会同步。

二、在电脑上运行这份源码（开发用途）

此源码为 React + TypeScript + Vinext，使用 Cloudflare 的本地开发模拟器保存数据库和图片。
Node.js 最低版本见 package.json（当前为 >=22.13）；包管理器版本为 pnpm@11.25.0。
先安装 Node.js 和对应版本 pnpm。在解压后的 borodin-game 文件夹打开终端。
本地命令根据项目现有脚本整理；尚未进行你的 Windows 电脑与手机的现场联测。

1. 安装依赖（首次需要联网）：

   pnpm install --frozen-lockfile

2. 构建，生成本地 Worker 配置：

   pnpm run build

3. 首次使用该本地数据库时，执行初始迁移（整行命令）：

   node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_watery_wallow.sql

   不要对已经执行过此迁移的本地数据库重复执行。数据库和上传图片保存在本地运行目录，和线上数据相互独立。

4. 开发服务允许局域网连接：

   pnpm run dev --hostname 0.0.0.0

   默认端口是 5173；如果终端显示其他端口，以下地址也要使用那个端口。

5. 主持人从本机浏览器访问 http://localhost:5173/ ，点击登录入口后创建房间。
   模板只在本机开发请求上提供模拟登录，不是线上 ChatGPT 账号登录。
   主持人仍使用 localhost 页面控制房间；玩家可在局域网地址上使用昵称加入。

6. Windows 终端可执行 ipconfig，查看当前 Wi-Fi/网络连接的 IPv4 地址。
   手机浏览器打开 http://实际的IPv4地址:5173/ ，输入房间码和昵称。
   注意：手机上的 localhost 指手机自己，不能用它连接主持人的电脑。
   主持人在 localhost 页面复制出的邀请链接也带 localhost，请手动替换为电脑实际的局域网 IP。
   若系统弹出防火墙提示，需要允许该服务在本次使用的局域网内接收连接。

再次启动时，通常只需要第 4 步；不要关闭正在运行服务的终端。
项目中的 install:ci 脚本用于原构建环境；本地直接使用上面的 pnpm install 命令即可。
开发服务器仅用于本地开发与联调，正式网上使用应部署生产版本。

三、修改人物图片和剧情

最简单：网页右上角“人物素材”上传 PNG / JPG / WebP，每张不超过 5MB，建议 3:4 竖图。
同一主持人房间内的玩家会读取同一组上传图片。

直接编辑源码：
- 人物图片放到 public/characters/。
- content/characters.json 的 image 字段填写 /characters/你的图片名.webp。
- content/story.json 修改台词、选项、回应和历史回顾。
- app/globals.css 修改颜色、字体与布局。
- README.md 提供项目结构与更多说明。

ZIP 不含线上房间记录或用户已经上传的图片；这些是服务器运行时数据。

四、迁移到其他网上平台

本项目有服务器、数据库和图片存储，不能只把页面文件上传到纯静态托管就实现多人投票。
现有线上版本由 Sites 管理登录、Cloudflare Workers、D1 数据库和 R2 图片存储。
部署到你自己的环境时，需要配置这些服务，并适配主持人的登录认证。
复制项目后，不会自动获得原网站的数据库、上传图片或登录配置。
